# 🐍 Python Fundamentals

A structured repository documenting my journey of learning Python from the ground up. This repository contains topic-wise examples, practice programs, assignments, mini-projects, and notes to build a strong foundation for Python programming and prepare for Data Science and Software Development.

---

## 📚 Repository Goal

The purpose of this repository is to:

* Learn Python fundamentals step by step.
* Write clean and well-documented code.
* Practice programming concepts through examples and exercises.
* Track learning progress using Git and GitHub.
* Build a solid foundation for Data Science, Machine Learning, and Backend Development.

## ▶️ Running Programs

Clone the repository:

```bash
git clone https://github.com/pratik-codeX/Python_Fundamentals.git
```

Move into the project directory:

```bash
cd Python_Fundamentals
```

Run any Python program:

```bash
python filename.py
```

or

```bash
python3 filename.py
```
